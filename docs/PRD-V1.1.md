## 1. 产品愿景与核心定位

### 1.1 一句话定位

> **"AI 脱口秀创作教练，陪你想、帮你选、促你改——而不是替你写。"**

### 1.2 核心价值观

| 原则 | 解释 |
|------|------|
| **引导而非替代** | AI 是教练，不是代笔。每一步都有选择权，每一步都能编辑。 |
| **过程即学习** | 用户不只是拿到一个段子，而是在创作过程中理解"为什么这样写好笑"。 |
| **可编辑是默认** | 所有 AI 生成内容都是"候选"，用户修改权高于 AI 输出。 |
| **教练永远在场** | 每张卡片都有 AI 教练点评，用户不是在做题，而是在被指导。 |

### 1.3 产品情感定位

用户使用这个产品的感受应该是：

- *"原来这个日常吐槽可以这样写！"*
- *"我知道为什么选这个角度了"*
- *"这个包袾放这儿真的更好笑"*
- *"AI 帮我找到我自己想不到的方向"*

用户不应该感受到的：

- *"AI 生成的段子不像我"*
- *"我不知道为什么要选这张卡"*
- *"我好像只是在点下一步"*
- *"这个产品直接帮我写了一篇稿"*

## 2. 目标用户画像

### 2.1 用户分类

#### 用户 A：脱口秀新手（核心用户，MVP 优先服务）

| 维度 | 描述 |
|------|------|
| **定义** | 有表达欲，但从未正式创作过脱口秀，或只看过/听过但没上过台 |
| **生活背景** | 25-35岁都市白领，有稳定工作，周末或偶尔想尝试新鲜事物 |
| **素材状态** | 有一肚子想吐槽的事（奇葩同事、相亲经历、父母催婚、租房踩坑），但不知道哪些能写成段子 |
| **创作痛点** | 不知道从哪里下手、不确定自己讲的东西好不好笑、写了草稿也不知道怎么改 |
| **使用场景** | 通勤路上、午休、睡前，碎片时间打开 App，随便聊聊自己的经历 |
| **核心需求** | 需要"被引导"——告诉他这个素材值不值得写、从哪个角度切入、怎么组织包袾 |
| **期望体验** | 像个贴心的老师，一步一步带着走，每一步都告诉我为什么 |
| **付费意愿** | 低，愿意为免费功能停留，但愿意为"帮我改稿"付费 |
| **技术能力** | 会用微信、小红书，能打字，操作越简单越好 |

**MVP 优先级：最高**

#### 用户 B：开放麦演员（核心用户，MVP 优先服务）

| 维度 | 描述 |
|------|------|
| **定义** | 已参加 1-5 次开放麦，有几个能讲的段子，但创作效率低、经常卡壳 |
| **生活背景** | 28-40岁，有固定工作或自由职业，兼职做脱口秀，把开放麦当当情绪出口 |
| **素材状态** | 积累了很多生活素材，有些写成了段子但讲起来不够好笑，有些只开了个头 |
| **创作痛点** | 找角度最难（素材有了但不知道从哪里切入）、改包袾最痛苦（知道不好笑但不知道怎么改）、压字数最难（铺垫太长超时） |
| **使用场景** | 专门抽时间创作（周末下午、创作瓶颈时），需要高效工具辅助 |
| **核心需求** | 需要"帮我找角度"和"帮我压字数"——不是重写，而是在我的素材基础上给方向 |
| **期望体验** | 专业、高效、尊重我已有的风格，能在 AI 建议里挑我能用的 |
| **付费意愿** | 中高，愿意为"高效创作工具"付费 |
| **技术能力** | 能熟练使用 App，愿意学习新工具 |

**MVP 优先级：最高**

#### 用户 C：成熟创作者 / 编剧（第一版暂不服务）

| 维度 | 描述 |
|------|------|
| **定义** | 有稳定创作习惯，上过正式演出，关注个人风格和内容品质 |
| **生活背景** | 30-45岁，可能是兼职演员、编剧或内容创作者 |
| **素材状态** | 有自己的创作方法论，需要的是辅助工具，不是教学工具 |
| **创作痛点** | 不希望 AI 乱改人设、不需要引导，需要版本管理和风格档案 |
| **核心需求** | 版本管理、风格一致、内容质量把控 |
| **期望体验** | 把我的素材和风格喂给 AI，让 AI 按我的风格生成候选内容 |
| **付费意愿** | 高 |
| **第一版策略** | **不服务**——这类用户的复杂需求（个人风格档案、版本管理、风格迁移）不在 MVP 范围 |

### 2.2 用户优先级决策

```
MVP 优先级
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
用户 A：脱口秀新手    ████████████  最高（核心）
用户 B：开放麦演员    ██████████    高（核心）
用户 C：成熟创作者    ░░░░░░░░░░░░  第一版不做
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**理由：** 用户 A 和 B 共同构成了"从 0 到 1 分钟稿"的强需求闭环。用户 C 的需求更复杂，会拖慢 MVP 速度。

## 3. MVP 范围定义

### 3.1 第一版必须做（MVP 闭环）

| 功能 | 具体范围 |
|------|----------|
| **单一素材创作流程** | 一个生活素材 → 诊断 → 前提 → 角度 → 包袾 → 草稿 → 1 分钟稿 |
| **手把手引导** | 每步有 AI 教练点评、为什么选这个、引导问题 |
| **卡片选择交互** | 所有 AI 输出以卡片形式呈现，支持选择/编辑/收藏 |
| **草稿编辑** | 用户可调整包袾顺序，可编辑任意卡片内容 |
| **自动保存** | 每一步操作后自动保存到本地，刷新不丢失 |
| **历史项目** | 查看所有创作项目，支持从项目详情页重新编辑 |
| **错误重试** | AI 生成失败时展示可理解错误，支持一键重试 |
| **移动端 + 桌面端** | 375px 移动端优先，桌面端自动适配 |

### 3.2 第一版不做（明确排除）

| 排除项 | 原因 |
|--------|------|
| 完整专场生成 | 超出 MVP 范围，1 分钟稿是核心 |
| 社区功能 | 后期考虑，用户创作闭环优先 |
| 多人协作 | MVP 不需要 |
| 视频生成 | 方向不对，这是文字创作工具 |
| 复杂 RAG 知识库 | 不做段子库，素材是用户自己的 |
| 复杂树状图 | 不做分支探索，线性流程更清晰 |
| 商业化支付 | MVP 验证产品价值后再考虑 |
| 复杂后台管理 | 基础管理界面即可 |

**4.3.3 前提选择页**

**路由：** `/create/premise`

- 未选中卡片：白色背景 + 灰色边框
- 最多选 1 个

**failed 状态：**
- 某张卡片下方显示：「生成失败，[重新生成这张]」

**进入下一步的条件：**
- 用户选择了一个前提（premise_id 不为空）

## 6. 创作流程详细规范

### 6.1 流程总览

```
[素材输入]
    │
    ▼
[AI 诊断] ── failed ──→ [重新诊断 / 修改素材]
    │
    ▼
[前提选择] ── failed ──→ [重新生成前提]
    │
    ▼
[角度选择] ── failed ──→ [重新生成角度]
    │
    ▼
[包袾选择] ── failed ──→ [重新生成包袾]
    │
    ▼
[草稿生成] ── failed ──→ [重新生成稿子]
    │
    ▼
[完成]
```

### 6.2 每一步详细规范

#### 步骤 1：素材输入

| 项目 | 内容 |
|------|------|
| **输入** | 用户在文本框中输入生活素材（100-500 字） |
| **AI 输出** | 无（本步骤纯用户输入） |
| **用户操作** | 输入文本 / 修改文本 / 点击「开始诊断」 |
| **自动保存** | 每 3 秒保存到 `localStorage`；点击「开始诊断」后保存到 `Project.material` |
| **失败状态** | 字数不足 100 字时，主按钮禁用并显示字数不足提示 |
| **进入下一步条件** | 字数 ≥ 100 字 AND 用户点击「开始诊断」 |
| **MVP 限制** | 仅支持中文文本输入；字数上限 500 字 |

#### 步骤 2：AI 诊断

| 项目 | 内容 |
|------|------|
| **输入** | `material.content`（素材文本）|
| **AI 输出** | `Diagnosis` JSON（见 5.1 诊断卡片规范）|
| **用户操作** | 查看诊断结果 / 刷新诊断 / 点击「看看这些方向 →」|
| **自动保存** | 诊断成功后保存到 `Project.diagnosis` |
| **失败条件** | 素材无法提取喜剧元素 / 网络错误 / AI 返回非 JSON |
| **失败处理** | 显示可理解错误 + 建议 + 重新诊断按钮 |
| **进入下一步条件** | 诊断成功 OR 用户点击「修改素材」|
| **Coach 反馈** | 显示整体教练点评（`diagnosis.coach_tip`）|

#### 步骤 3：前提选择

| 项目 | 内容 |
|------|------|
| **输入** | `material.content` + `diagnosis` |
| **AI 输出** | `Premise[]`（3-5 个前提卡片）|
| **用户操作** | 浏览卡片 / 收藏卡片 / 编辑卡片 / 选择卡片 / 刷新卡片 / 点击主按钮 |
| **自动保存** | 用户选择后保存 `Project.premise_id` |
| **失败条件** | AI 生成失败 / 返回数量不足 3 个 |
| **失败处理** | 在失败的卡片位置显示「生成失败，[重新生成]」|
| **进入下一步条件** | 用户选择了 1 个前提 |
| **Coach 反馈** | 每张卡片显示 `coach_tip` 和 `next_question` |
| **MVP 限制** | 单选，不做多选 |

#### 步骤 4：角度选择

| 项目 | 内容 |
|------|------|
| **输入** | `material.content` + `selected_premise` |
| **AI 输出** | `Angle[]`（3-5 个角度卡片）|
| **用户操作** | 浏览卡片 / 收藏卡片 / 编辑卡片 / 选择卡片 / 刷新卡片 / 点击主按钮 |
| **自动保存** | 用户选择后保存 `Project.angle_id` |
| **失败条件** | AI 生成失败 / 返回数量不足 3 个 |
| **失败处理** | 在失败的卡片位置显示「生成失败，[重新生成]」|
| **进入下一步条件** | 用户选择了 1 个角度 |
| **Coach 反馈** | 每张卡片显示可笑潜力标签（🔥/⚡/❄️）和 `coach_tip` |
| **MVP 限制** | 单选 |

#### 步骤 5：包袾选择

| 项目 | 内容 |
|------|------|
| **输入** | `material.content` + `selected_angle` + `selected_premise` |
| **AI 输出** | `Punchline[]`（6-10 个包袾零件卡片）|
| **用户操作** | 浏览卡片 / 收藏卡片 / 编辑卡片 / 选择/取消选择（多选）/ 调整顺序 / 点击主按钮 |
| **自动保存** | 每次选择变化后保存 `Project.selected_punchline_ids` |
| **失败条件** | 某个包袾生成失败（不影响其他包袾，不阻塞流程）|
| **失败处理** | 失败卡片单独显示错误状态，可单独重试 |
| **进入下一步条件** | 用户至少选择了 1 个包袾 |
| **Coach 反馈** | 每张卡片显示 `placement` 建议和 `coach_tip` |
| **草稿预览** | 页面底部实时显示已选包袾的排列顺序（可拖拽调整）|
| **MVP 限制** | 多选；至少选 1 个 |

#### 步骤 6：草稿生成

| 项目 | 内容 |
|------|------|
| **输入** | `material.content` + `diagnosis` + `selected_premise` + `selected_angle` + `selected_punchlines[]` |
| **AI 输出** | 最终稿文本（500-800 字）+ 教练点评 |
| **用户操作** | 查看稿子 / 编辑稿子 / 重新生成 / 保存草稿 / 标记为完成 |
| **自动保存** | 稿子生成成功后保存到 `Project.final_script`；用户编辑后实时保存 |
| **失败条件** | AI 无法组合包袾 / 超时 / 网络错误 |
| **失败处理** | 显示建议（多选包袾/换前提）+ 重新生成按钮 |
| **进入完成条件** | 用户点击「标记为完成」OR 自动检测到稿子已稳定保存 |
| **Coach 反馈** | 显示整体结构点评和建议（`这个包袾节奏不错` / `第三段的铺垫稍长，可以删掉最后一句`）|

## 11. 风险评估

### 11.1 AI 输出质量不稳定

| 项目 | 内容 |
|------|------|
| **风险描述** | AI 生成的诊断、前提、角度、包袾可能不符合用户预期 |
| **影响程度** | 高 |
| **解决方案** | Prompt 优化 / 多次生成择优 / 用户编辑权 / coach_tip 引导 / 人工标注样本 |

### 11.2 用户不知道如何选择

| 项目 | 内容 |
|------|------|
| **风险描述** | 用户面对 3-5 张卡片，不知道选哪个更好 |
| **影响程度** | 中 |
| **解决方案** | comedy_potential 标签 / why_it_works 说明 / next_question 引导 / 不选也行 |

### 11.3 移动端信息过载

| 项目 | 内容 |
|------|------|
| **风险描述** | 移动端屏幕小，每页展示 3-5 张卡片可能造成信息过载 |
| **影响程度** | 中 |
| **解决方案** | 卡片折叠设计 / 分批展示 / 单操作原则 / 上下文提示 |

### 11.4 自动保存失败

| 项目 | 内容 |
|------|------|
| **风险描述** | 网络不稳定或浏览器存储满，导致数据丢失 |
| **影响程度** | 高 |
| **解决方案** | 本地优先 / 保存状态反馈 / 草稿恢复机制 / 防抖 |

### 11.5 JSON 解析失败

| 项目 | 内容 |
|------|------|
| **风险描述** | AI 返回的 JSON 格式不标准，导致解析失败 |
| **影响程度** | 中 |
| **解决方案** | 严格 JSON 提取 / 容错解析 / 降级处理 / 日志记录 |

### 11.6 内容不像用户本人

| 项目 | 内容 |
|------|------|
| **风险描述** | AI 生成的包袾语气与用户本人差异大 |
| **影响程度** | 高 |
| **解决方案** | 口语化处理 / 用户编辑权 / coach_tip 提供语气建议 |

### 11.7 用户误以为产品是「一键生成段子」

| 项目 | 内容 |
|------|------|
| **风险描述** | 用户带着「AI 一键生成」的期待进来，感到困惑或失望 |
| **影响程度** | 高 |
| **解决方案** | 首页明确说明 / 创作前引导 / 教练人设 / 每步学习感 / 对比文案 |

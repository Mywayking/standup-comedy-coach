# 🎤 手把手教你玩脱口秀

> **"让你的生活素材，变成上台的段子"**

AI 脱口秀创作教练产品 —— 帮你从生活素材写出上台段子。

## 产品定位

这不是 AI 段子生成器，而是 **AI 脱口秀创作教练**。

AI 不直接替用户写完整稿，而是通过分步骤引导、卡片候选、用户选择和持续追问，陪用户一步步完成创作。

## 核心功能

- 📝 **素材输入** — 输入你的生活素材（100-500字）
- 🔍 **AI 诊断** — 分析素材的冲突、情绪、可笑点、适合风格
- 💡 **前提生成** — 从素材中提炼 3-5 个可写的核心前提
- 🎯 **角度发散** — 基于前提找到具体的切入角度
- 🎭 **包袱生成** — 生成多个包袱零件供选择
- 📄 **草稿生成** — 组合成 1 分钟开放麦稿
- 💾 **自动保存** — 所有创作自动保存
- ✏️ **可编辑** — 所有内容都可编辑

## 创作流程

```
素材输入 → AI 诊断 → 前提选择 → 角度选择 → 包袱选择 → 草稿生成 → 完成
```

## 技术栈

- **前端**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **状态管理**: Zustand
- **数据库**: SQLite (开发) / PostgreSQL (生产) via Prisma
- **AI**: OpenAI GPT-4o
